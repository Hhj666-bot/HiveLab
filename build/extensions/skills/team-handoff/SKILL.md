# 团队交接

先读取用户当前要求和已有结果，按实际证据整理：

1. 目标与已确认的约束。
2. 已完成的工作与修改文件位置。
3. 已做的验证、真实结果与尚未验证的部分。
4. 剩余问题、阻塞条件和建议下一步。

用户要求文件时使用 HiveLab 的 create_file 工具输出 Markdown；该插件未启用时直接提供正文，并说明无法创建下载附件。
需要用户作决定时使用 ask_user，等待实际回答；没有工具时明确提问，不能假定同意。
不要自行发送消息、发起新的模型调用或改变其他成员的权限。只有用户明确授权时才进行交接动作。
