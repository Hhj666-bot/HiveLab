# 界面分层

整个窗口是一个层叠结构，所有界面都按它布局。层级集中定义在 `src/renderer/styles/tokens/layers.css`，不要再写裸数字。

| 层 | 变量 | 内容 |
| --- | --- | --- |
| 壁纸 | `--layer-wallpaper` | 全窗口的背景，由 `SidebarLayout` 挂载，全局只有一个 |
| 界面 | `--layer-interface` | 侧栏、顶栏、立绘、会话，以及并排显示的文件预览和终端 |
| 功能层 | `--layer-panel` | 设置等覆盖在界面上的窗口 |
| 提醒 | `--layer-notice` | 成员提醒和提示 |
| 菜单 | `--layer-menu` | 右键菜单、下拉菜单 |
| 气泡 | `--layer-bubble` | 右下角待处理气泡 |

规则：

1. 壁纸永远铺满整个窗口，不随界面移动或改变大小。入场动画只移动界面层。
2. 界面是否透出壁纸，只由该界面自己的透明度决定。侧栏透明度调到 0，就看不到身后的壁纸。
3. 液态玻璃是材质，不是布局。它只改变表面的外观，开和关时所有元素的位置和尺寸必须一致，`tests/startup-electron-smoke.mjs` 会检查这一点。

已移除“壁纸延伸到左侧栏”：分层后壁纸总在最底层。旧设置里的 `extendToSidebar` 会被忽略。
