# 工位会话文件与清理

新建个人工位话题会建立 `desks/<member>/sessions/<日期>_<完整会话 ID>/`，并将它保存为会话的实际工作目录。标题修改不移动目录。原有会话继续使用原位置，文件树的“历史未分类”提供访问和逐个文件归类入口；外部项目保持原项目结构。

文件树支持“当前会话 / 全部会话 / 共享资料 / 原有文件”。“原有文件”即之前的“历史未分类”。全部会话也包括升级前的会话；共用同一目录的旧会话会有明确提示，文件仍在原位置，不推断文件归属，不更改原生会话工作目录。所有会话使用稳定的文件视图标识，全部会话通过虚拟分组访问原路径，也支持成员个人目录之外的原有工作副本。当前会话随工位话题切换。会话目录保持固定，目录改名被拒绝；文件改名会同步保留标记。共享资料放在成员目录下的 `shared/`，文件右键可以复制到共享资料。

工位“文件管理”、文件树底部和“设置与连接 → 工作台 → 工位文件管理”都可进入清理与回收区。设置独立保存：回收区默认保留 7 天，0 表示永久保留；闲置筛选默认 30 天；临时文件默认 7 天。三个天数均可修改。自动回收临时文件默认关闭，只识别新会话的 `_临时/`；成果不会因为归档或闲置而自动删除。

文件管理同时扫描新会话目录、原有工位文件和共享资料；同一个旧共用目录合并为一组，避免重复展示和统计。旧目录中的新会话子目录、共享资料在各自分组显示，原目录不重复扫描这些文件。没有旧会话记录时也能管理成员目录里留存的原有文件。项目和外部工作目录按物理位置合并展示，仅供查看并引导回文件树管理，避免批量清理原项目。

手动清理先选择文件并预览，再将普通文件逐个移入本机 `desk-recycle/`；原有工位文件和共享资料也支持标记保留、手动回收与恢复。聊天记录和原目录保留。运行中的会话或终端、未保存编辑、保留标记、隐藏配置目录及明确的跨分组绝对路径引用均受到保护。清理执行前重新检查文件版本与保护状态；失败项保持原位置并显示原因。自动回收临时文件仍只扫描新会话目录，不处理旧共用目录、共享资料或项目源码。

恢复使用独占创建，遇到同名文件不会覆盖。永久清空需要再次确认。应用运行期间每 15 分钟检查回收期限；修改后的天数也用于已有回收文件。过期清空只处理登记过的回收文件；回收和恢复的未完成记录会按磁盘现状恢复。移入回收区本身不释放空间，永久清除后才释放。

针对性检查：`tests/desk-files.test.ts` 验证新话题目录、旧文件保留、分组、清理保护、预览后变化、恢复冲突与可配置期限；不连接模型账号。
