# 工作区文件与终端

右上角在首页、茶歇室、个人工位、圆桌、项目会议室和个人汇报中常驻四个集合：**文件预览、终端、文件、外观**。顶栏保持展开，最大化文件预览不会隐藏这些入口。

“文件”收纳会话文件、文件管理、个人文件夹和切换文件夹。个人工位继续沿用原来的话题目录切换；其他页面使用当前文件工作区，并可选择新的本机文件夹。“外观”直接打开统一外观面板，背景、聊天、界面材质和卡片透明度在同一处调整，配置范围和保存方式沿用原有逻辑。

聊天页面在右上角四个按钮下方显示搜索栏，首页不显示。选择“本会话”搜索当前正在查看的话题，或选择“全部会话”搜索已保存的工位、茶歇室、圆桌、项目会议室和个人汇报正文；输入文字后按 Enter 或点击搜索图标。结果显示在文件预览左侧的独立分栏，沿用顶栏透明度和液态玻璃参数，不关闭已有文件标签。匹配文字用小胶囊标记，点击结果会切换会话、定位消息并高亮正文；旧工位话题会切回其所属文件夹。搜索结果在跳转后保持打开，清空输入、按 Esc 或关闭搜索侧栏会取消搜索并清除正文高亮。结果分批加载，搜索不调用模型。

左侧栏的折叠状态与宽度在主页、聊天和文件页共用，切换页面不再改变布局；旧版优先采用聊天页的侧栏设置，并迁移到全局偏好。“思考与操作”共用回复气泡的颜色和透明度；代码块、表格、运行诊断、参数、命令与结果使用更不透明一些的半透明衬底，随回复透明度调整。玻璃开启、关闭，以及白天、夜晚模式均使用这一规则；开启玻璃时再叠加折射和高光。

“外观 → 自适应文本对比色”可填写对比不足的持续时长与颜色切换后的保持时长，单位为秒，即时生效并保存到本机；默认分别为 3.5 秒和 12 秒。跨行代码胶囊不再叠加背景模糊，保留逐行圆角底色，避免模糊旁边的正文。

站内消息与操作提示在顶栏下方居中显示为紧凑圆角浮层，液态玻璃和透明度沿用顶栏设置。多条消息逐条查看，点击消息可进入原会话或处理待办；不再显示关闭按钮，对应会话、话题或待办界面获得焦点时自动清除相关消息。成员工作时显示特征色光圈并缓慢闪烁，完成后有未读结果或等待回应时改为常亮；侧栏折叠时光圈围绕头像，展开时围绕整张成员卡。侧栏边缘箭头默认只显示淡色图标，悬停和键盘聚焦时再强调。

回复气泡与思考栏默认使用发言成员的特征色，原有自定义颜色保留。“回复气泡与思考栏 / 我的消息 / 输入框”三组颜色均提供“使用特征色”按钮，也可明确选择跟随主题或自选颜色，原有透明度与应用范围保持独立。多人房间的回复逐条跟随作者，个人工位的输入框与我的消息可跟随当前成员。

文件预览底部提供缩小、恢复 100% 与放大按钮，范围为 50%–400%，每个打开的标签分别保留缩放比例。Markdown、网页、代码、办公文档、PDF 与图片均可缩放；编辑源码时缩放只改变字号。文件标签和源码切换工具栏保持原大小。

右侧文件标签、预览/源码切换、复制和刷新合并在一行；下载、图片缩放和工作区文件位置等操作收到各自的“更多”菜单。文件标题只在标签中显示一次。文件树打开的可编辑文件仍支持编辑、保存和未保存提醒，保存按钮在编辑或有未保存修改时出现。

左侧“工作台 / 文件”共用原来的侧栏，切换不会关闭对话或文件。文件页可以选择项目、成员个人文件夹、工位当前文件夹、任务副本，或通过系统对话框打开其他文件夹。

单击文件在右侧标签页打开。Markdown、文本与代码支持编辑，Ctrl+S 保存；文件关闭或退出程序时会提醒未保存的修改。保存保留 UTF-8 BOM、UTF-16 字节序及 Windows 换行，磁盘文件已改变时拒绝覆盖。图片、PDF 和 Word 支持内置预览，Excel 显示已保存的单元格值，PowerPoint 显示各页文字；办公文档的完整排版编辑通过“用默认应用打开”完成。Excel 预览每张表最多 500 行、80 列；文本编辑上限 2 MB，办公文档与 PDF 预览上限 20 MB。

HTML/HTM 默认显示网页，工具栏可切换“查看源码 / 排版预览”；从文件树打开时也可编辑并保存源码。页面使用独立协议与 `sandbox="allow-scripts"` iframe，支持同目录及子目录的 CSS、JavaScript、图片、字体和 HTTPS 外部资源，不能访问工作台界面或调用工作台接口。网页源码上限 2 MB，本地资源与音视频上限 20 MB；需要后端服务、模块构建、表单提交或其他服务端能力的项目仍应使用自身的运行环境。

CSV/TSV 显示表格，也可查看源码；支持带引号的逗号、换行及双引号，每份最多 500 行、80 列。常见音频（MP3、WAV、OGG、M4A、AAC、FLAC、Opus）及视频（MP4、WebM、M4V、OGV、MOV）使用内置播放器，不自动播放；实际播放取决于 Electron 支持的编码，解码失败时提示用默认应用打开。图片新增 AVIF；SVG 与 HTML、Markdown、CSV/TSV 一样提供源码 / 预览切换。

旧版 DOC/XLS/PPT、RTF、OpenDocument、iWork、HEIC/HEIF、TIFF、PSD、压缩包与数据库文件尚无内置内容预览，显示明确提示。PPTX 仍为文字预览，XLSX 为保存值表格预览；均不等同于完整 Office 排版。

尚无消息时的欢迎卡片在聊天可用内容区居中，开启液态玻璃后使用折射与模糊材质。“外观 → 页面背景 → 欢迎卡片透明度”可即时调整底色透明度，按页面保存，也可勾选同步所有界面。

文件树支持新建文件、文件夹、重命名、复制相对路径、在资源管理器中显示及移入系统回收站。目录按需展开，每个目录最多显示 3000 项；筛选作用于已展开的文件。已登记工作区和系统目录选择器提供目录授权，路径穿越、NTFS 数据流及指向工作区外的链接不会被当作文件读取或写入。

“打开终端”及 Ctrl+反引号在底部打开真实本地终端，Windows 使用 PowerShell。支持多个终端、交互输入、Ctrl+C、拖动调整高度；收起面板会保留进程，关闭当前终端会结束对应进程，退出应用会关闭所有终端。新终端以当前工作区为起点，可从目录右键直接打开；人手输入的终端命令具有当前用户的系统权限。终端不自动运行任何项目命令。

“设置与连接 → 外观”集中提供主题、侧栏宽度与显示方式、全局侧栏透明度、各页面背景、统一聊天外观和首页人物疏密。工作台与文件树共用透明度，只改变底色；所有页面同步，旧版本按页保存的透明度会在首次启动时自动迁移成这一个全局值。页面内原有背景与聊天外观入口保留并即时同步。壁纸始终铺满整个窗口，分层规则见 `docs/ui-layers.md`。各页面壁纸继续按页面标识独立保存。

文件工作区中同一成员的个人目录与当前工位指向同一实际位置时合并为一个“工位文件夹”。旧工作区标识仍能解析到原目录；当前工作文件夹确实不同时保留独立入口。合并只改变列表显示，不移动或删除任何文件。

实现入口：`src/main/workspace-files.ts`、`src/main/workspace-terminal.ts`；界面为 `src/renderer/workspace-*.tsx`。使用 xterm.js 与 node-pty 实现真正的 PTY，PDF 使用 PDF.js；办公文件不运行宏或外部关系。

验证：`tests/workspace-files.test.ts` 覆盖文件边界、原编码保存、冲突及真实终端；`tests/workspace-tools-electron-smoke.mjs` 在隔离打包程序中覆盖界面、各类文件、终端和壁纸持久化。`tests/file-preview-sidebar.test.ts` 覆盖格式分流、资源范围、编码与媒体分段；`tests/file-preview-electron-smoke.mjs` 覆盖实际 CSP 下的 HTML 本地资源与交互、源码切换、CSV、音视频播放及已有格式。不需要真实模型账号。
