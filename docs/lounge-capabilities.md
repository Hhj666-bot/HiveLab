# 茶歇室能力开关

茶歇室顶部的“能力：受限 / 能力：工位”按钮决定普通聊天发言能否使用与个人工位相同的工具。

- **受限**：保留现有聊天模式，禁用原生命令和写入权限；默认采用此模式。
- **工位**：普通聊天发言沿用每个人物的执行端、工具、插件和权限模式，可按用户要求处理文件、命令和任务。权限仍由人物设置和执行端能力决定，不会把“请求批准”改成“完全访问”。工作文件默认保存在茶歇室目录。

讨论运行时先暂停并等待当前发言结束，再切换。选项保存在本机数据库，跨话题和重启保留。聊天记录不删除；切换时保留旧原生会话为历史，下一轮使用新上下文并重新提供聊天材料。自动问候、举手、独立生图和纪要沿用原来的专用权限；项目会议室和圆桌不受茶歇室按钮影响。

工位能力下沿用正常任务运行时限，不使用纯聊天的 90 秒空闲回复超时，以支持耗时工具任务。

实现：`RoomState.capabilityMode`、`Session.loungeCapabilityMode` 和 `room.capabilities` RPC；`lounge-capabilities.ts` 决定可启用的发言类型；引擎同时更新实际执行端权限与完整/增量聊天提示。Codex 的工位生图能力也跟随选择。

验证包括：原生权限策略对比、已有聊天保留、权限模式隔离、自动任务保持原模式、运行中拒绝切换、其他房间不能提权、完整与增量提示、真实 Electron 的按钮切换、折叠/展开、窄窗口以及重启持久化。测试使用隔离数据，无付费模型请求。
