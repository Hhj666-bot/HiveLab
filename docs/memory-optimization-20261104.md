# HiveLab 内存排查与优化（2026-11-04）

## 结构
- `src/main`：Electron 窗口、IPC、浏览器侧栏、本地资源协议、文件预览及终端。
- `src/backend`：独立 utility process；Engine 调度、SQLite Store、成员适配器、会话运行池、插件和工作区。
- `src/renderer`：React 界面、聊天、文件预览、动态壁纸、液态玻璃与文字颜色采样。
- `src/shared`：跨进程类型、状态差量同步和公共规则。
- `scripts`、`tests`：构建、部署、隔离测试和浏览器验证。
- 上级 `runtime` 是当前运行版本，`local-data` 是数据及成员运行环境，`archive` 是历史备份；磁盘体积不等于运行内存。

## 现场观察
通过 Windows 进程信息采样，主界面 renderer 工作集约 384 MB，后台 Node utility 约 238 MB，GPU 约 215 MB，主进程约 107 MB，另外两个 renderer 约 67 MB、21 MB。成员工具也有独立进程。这是单次工作集采样，包含共享页面，不能直接解释为私有内存或内存泄漏；未采集连续堆快照。

## 已修改
1. `home-background.tsx`：保留已访问页面的图片预加载，避免返回时重新解码；仅在该页面预加载更新、图片源已变更时清除旧源。不限制为两张。
2. 动态壁纸沿用原有的最后一个隐藏场景保留策略；已撤回 30 秒卸载机制，避免返回时重新加载。用户要求日常流畅优先，因此不以主动清掉仍可复用的视觉资源换取内存数字下降。
3. `snapshot-sync.ts`：有效的按 ID 同步数组只保存逐行 JSON，取消整段 JSON 副本及其重复序列化；仍检测原地修改、顺序变化、删除及非法 ID 回退。不会裁剪聊天记录。
4. `liquid-refraction.ts`：纹理编码后立即清零临时 canvas，释放其原生像素缓冲。

## 动效触发响应修复
针对侧栏折叠/展开、首页和工位切换：
- 玻璃折射纹理复用平坦区重复行列计算。浏览器独立测量中约 700×650 纹理平均生成耗时从 16.18 ms 降到 5.08 ms；该数字是纹理计算耗时，不是整体动效延迟。修改前六组像素摘要及强度对比一致，四组固化为回归测试。
- 页面转场改为在复制前排除不可见聊天行。1000 条、约 42005 节点的合成历史，只复制 215 个节点，保留完整滚动高度、可见行、节点对应关系和草稿。
- 保留原有动画时长、弹簧参数、图片预加载和动态壁纸复用。新动态壁纸首次加载仍遵守原有“背景就绪后同步翻页”规则。
- 类型检查、构建、9 项相关单元测试、长历史浏览器测试、侧栏切换浏览器测试、真实 Electron 工位使用与转场测试通过。
- 轻量侧栏测试未复现明显长延时（修改前首帧回调约 9–20 ms），上述修复降低已确认的同步计算开销；尚不能断言覆盖全部偶发卡顿。

## 使用真实历史复现侧栏延时
从 `D:\HiveLab\local-data\data\hivelab.sqlite` 以 SQLite 只读连接读取两份实际话题，分别为 64 条/43192 字符和 46 条/41144 字符。消息仅传入隔离浏览器的内存，采用实际 RoomView、侧栏、玻璃及自适应文字组件；所有操作接口为测试替身，外网请求被拦截。未复制账号配置，也未修改原始消息。

64 条消息场景中，修改前四次点击到侧栏宽度变化超过 1px 的耗时为 355、411、335、419 ms。优化后同一场景一轮为 187、175、112、170 ms。数据来自 1500×950 隔离浏览器、开发构建和 CPU 采样下的重复开合；不等同于所有设备的日常版时延。

原因与修改：
- 外观偏好的订阅过宽，侧栏开关也触发主题及聊天树重绘；主题色、动效档位和浮动聊天布局改为只订阅所用字段。
- 布局测量重复触碰长历史；侧栏运动期间沿用抽屉已有策略，暂时固定屏幕外消息高度，并在结束后恢复。
- 玻璃尺寸读取/写入交错，且会强制测量暂停排版的历史；改为批量读取，再写入，并跳过这些历史节点。侧栏动画期间不全量扫描聊天玻璃。
- 自适应文字在侧栏运动期间只处理侧栏，落定后复核配色；不清空全部颜色再重刷。
- 回归检查另发现重复尺寸通知会取消仍在飞行的成员选中气泡；目标位置未变时保持原动画。

保留全部消息、背景预加载、玻璃材质和动画参数。性能仍有改善空间，不声称消除所有延时。复测入口为 `tests/ui/history-sidebar-profile.mjs`，需显式设置 `HIVELAB_HISTORY_DB`，可用 `HIVELAB_HISTORY_RANK=1` 选第二个长话题；测试代码不内嵌真实消息。
